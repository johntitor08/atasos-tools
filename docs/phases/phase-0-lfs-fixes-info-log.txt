--------------------------------------------------------------------------------
THE THREE BUGS (root cause = LFS build was done wrong)
--------------------------------------------------------------------------------
BUG 1 — /sbin was a REAL DIRECTORY instead of the merged-/usr symlink /sbin->usr/sbin
  Evidence: /bin was a correct symlink but /sbin was a directory owned by eren,
  and it contained a stray "/sbin/sbin -> usr/sbin" symlink. That stray link is
  the fingerprint of running `ln -s usr/sbin /sbin` AFTER /sbin already existed as
  a directory (ln drops the link INSIDE the dir instead of replacing it).
  Impact: original boot.log showed
      modprobe@*.service: Unable to locate executable '/sbin/modprobe'
  because the kernel/systemd look for /sbin/modprobe. (systemd here is built
  -KMOD, so it shells out to the /sbin/modprobe binary.) Later worked around by
  hand-adding kmod symlinks inside the stray /sbin dir, so modprobe worked, but
  the layout stayed wrong (duplicate util-linux binaries in /sbin AND /usr/sbin
  that can drift, plus the junk /sbin/sbin).

BUG 2 — System directories owned by user "eren" (uid/gid 1001) instead of root
  Affected dir NODES (files inside were already root-owned): /usr, /usr/bin,
  /usr/sbin, /usr/lib, /usr/libexec, /var, /usr/share, /usr/include, and more
  (scattered, not just top level).
  Impact: LOCAL PRIVILEGE ESCALATION. eren owning /usr/bin, /usr/sbin (mode 0755)
  means eren can rename/replace any binary root later executes (sudo, su, service
  binaries, etc.). Classic "forgot chown -R root:root" LFS mistake.

BUG 3 — Root fs mounted "with errors, running e2fsck is recommended"
  systemd-fsck-root is skipped every boot because the kernel cmdline mounts root
  `rw` (ConditionPathIsReadWrite=!/), so the ext4 error flag never gets cleared.
  NOTE: this was only present on the OLD lfs.img state. The LIVE qcow2 boots
  clean (no error flag) — so nothing to fix there.

--------------------------------------------------------------------------------
WHAT WAS FIXED, ON WHICH IMAGE, AND HOW
--------------------------------------------------------------------------------
== lfs.img (fixed offline, NO root/mount needed, using e2fsck + debugfs -w) ==
  Bug 3:  e2fsck -fy lfs.img   (replayed journal, cleared error flag, fixed counts)
  Bug 1:  Built a debugfs script that hardlinked /sbin/nologin into /usr/sbin,
          rm'd the 41 duplicate/junk /sbin entries, rmdir'd /sbin, then
          `symlink /sbin usr/sbin`.  Ran a final `e2fsck -fy` (came back CLEAN).
          Result: /sbin -> usr/sbin ; /sbin/modprobe -> /usr/sbin/modprobe ->
          ../bin/kmod (real 487 KB binary) ; /usr/sbin/nologin preserved.
  Bug 2:  debugfs `sif <dir> uid 0` / `gid 0` on the security-critical dirs
          /usr, /usr/bin, /usr/sbin, /usr/lib, /var, /usr/libexec -> root:root.
          (A FULL recursive chown of every scattered 1001-owned dir on lfs.img
          was NOT done offline — that needs a root mount / find -uid 1001. The
          flat binary PATH dirs, i.e. the actual privesc hole, ARE fully closed.)

== lfs.qcow2 (LIVE atasOS) ==
  Bug 2 — done from INSIDE the running guest as root (complete recursive fix):
          chown -R root:root /usr /sbin /opt /srv /etc
          find /var -xdev -uid 1001 -exec chown root:root {} +
          Verified: /usr, /usr/bin, /usr/sbin, /usr/lib, /var, /usr/libexec,
          /sbin all now root:root.
  Bug 3 — not present (live boot mounts clean).
  Bug 1 — done OFFLINE via qemu-nbd, VM powered off, on the host:
          sudo modprobe nbd max_part=8
          sudo qemu-nbd --connect=/dev/nbd0 /home/eren/Belgeler/lfs/lfs.qcow2
          # then a guarded script: verify UUID cf3cf64c, e2fsck -fy /dev/nbd0,
          # mount, preserve /sbin/nologin into /usr/sbin, rm -rf sbin,
          # ln -s usr/sbin sbin, verify, umount, final e2fsck (CLEAN),
          # qemu-nbd --disconnect /dev/nbd0
          Verified: /sbin -> usr/sbin ; /sbin/modprobe resolves to /usr/bin/kmod ;
          /usr/sbin/nologin present as root:root. nbd disconnected, image unlocked.
