# phase-e-atspkg

> atasOS Phase E: atspkg paket yöneticisi yazıldı, test edildi ve guest'e kuruldu (2026-07-19); FUSE+debugfs dağıtım tarifi

Phase E (Polish) 2026-07-19'da başladı. **E1 = `atspkg` paket yöneticisi: YAZILDI, host'ta sahte kökte tam test edildi ve GUEST'E KURULDU** (`/usr/bin/atspkg` 0755 root:root + `/var/lib/atspkg/db` `/var/cache/atspkg` `/etc/atspkg`; snapshot #25 `pre-atspkg-2026-07-19` önce alındı).

**Dağıtım tarifi (root'suz, VM kapalıyken — tekrar kullanılabilir):** nbd modülü çekirdek güncellemesi yüzünden yüklenemiyorsa: `qemu-storage-daemon --blockdev node-name=img,driver=file,filename=lfs.qcow2 --blockdev node-name=qcow,driver=qcow2,file=img --export type=fuse,id=exp,node-name=qcow,mountpoint=raw.img,writable=on` → **lfs.qcow2 içeriği bölümlemesiz SAF ext4** (lfs.img gibi; MBR'de sadece grub kodu) → `debugfs -w` ile mkdir/write/sif (uid/gid/mode elle ayarla!). Bitince e2fsck -fn + daemon kill + `qemu-img check`. Hepsi temiz çıktı. Host sudo parolası: kullanıcı gerekirse veriyor; fuse2fs/guestfish host'ta yok.
